# EE470 ESP8266 Distance and Light Monitor

**Author:** Hamza Alshamasneh  
**Course:** EE470 - Internet of Things

## Project Description

This project uses a NodeMCU ESP8266 to measure distance and light.
A pushbutton sends measurements as node_1, while a tilt switch sends
measurements as node_2. Each message contains both sensor readings
and the timestamp generated by the ESP.

The ESP sends the measurements to a PHP receiver on Hostinger.
The receiver validates and stores the data in MySQL. A webpage
displays the selected node's measurement count, statistics and plots.

## Hardware and Software

- NodeMCU ESP8266 ESP-12E
- HC-SR04 ultrasonic distance sensor
- Photoresistor module
- Pushbutton
- Tilt switch module
- Two 10 kΩ resistors for the ultrasonic Echo voltage divider
- Visual Studio Code and PlatformIO
- Arduino C++, PHP, MySQL and Chart.js

## Pin Connections

| Component | ESP connection |
|---|---|
| Ultrasonic TRIG | D1 |
| Ultrasonic ECHO | D2 through the voltage divider |
| Photoresistor signal | A0 |
| Pushbutton | D5 to GND |
| Tilt switch signal | D6 |

All components share a common ground. The photoresistor and tilt
modules use 3.3 V. The ultrasonic sensor uses the verified 5 V supply.
The photoresistor signal must stay within the board's A0 input range.

## Main Features

- One new measurement per pushbutton or tilt activation.
- Both distance and light are included in each message.
- USB Serial menu for selecting the time zone.
- Time synchronization using timeapi.io and NTP.
- Display of IP address, MAC address, RSSI and memory information.
- Automatic retries every 30 seconds until delivery is confirmed.
- Retries preserve the original timestamp and sensor values.
- Only registered nodes are accepted.
- Duplicate measurements do not create extra records or increase counts.
- Node-specific statistics, plots and stored readings.
- Manual refresh or automatic refresh every 10 seconds.

Light is recorded as a raw ADC value from 0 to 1023, not lux.
In the tested circuit, higher readings indicate darker conditions.

## Database

The project uses these three related tables:

- sensor_register: registered node information.
- esp_sensor_data: timestamps, distance, light and time-zone information.
- sensor_activity: valid, unique measurement counts.

An AFTER INSERT trigger increases the counter only when a new
measurement is successfully stored.

## Setup

1. Open the firmware project in VS Code with PlatformIO installed.
2. Enter the Wi-Fi credentials and receiver URL in src/main.cpp.
3. Create the database tables and counting trigger.
4. Enter the database connection details in the PHP files.
5. Upload the PHP files to the web server.
6. Build and upload the firmware to the ESP.
7. Open the Serial Monitor at 115200 baud.
8. Select a time zone or wait for the Pacific default.
9. Wait for READY, then release/reset the switches before testing.

## Operation

Pressing the pushbutton captures a measurement for node_1.
Activating the tilt switch captures a measurement for node_2.

The ESP sends an HTTPS GET request and checks the HTTP response
and JSON acknowledgement. A matching stored or already_stored
response confirms delivery. Otherwise, the original message remains
queued for another attempt.

Pending messages are stored in RAM and are lost if the ESP resets
or loses power. The lab firmware uses encrypted HTTPS with server
certificate verification disabled.
